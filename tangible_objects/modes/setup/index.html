Loads the completion config from completion_config_path; falls back to [CompletionConfig::default] when the file is absent or unreadable. CLI --completion-* flags override individual fields on top of this.

Loads the startup dead zones from the runtime store (dead_zones.d/ under the config directory - Lifetime::Persistent registrations reload with the daemon). Invalid files are reported and skipped.
load_field_sets

Loads figure patterns from a profile directory (default: profiles/).
load_spells
Loads the startup spells from the runtime store (spells.d/ under the config directory - Lifetime::Persistent registrations reload with the daemon). Invalid files are reported and skipped.
resolve_device
Resolves the device argument: an explicit --device path wins; otherwise auto-detect via vendor:product against the device registry (builtin + --device-profiles dir) - succeeds only when exactly one known touchscreen is attached.
