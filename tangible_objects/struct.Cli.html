Expand description

Capacitive touch-figure prototype - detection, recording and analysis of tangible figures on multitouch surfaces.

Exactly one mode flag selects the action; all other options configure it. --record is ambiguous: alone it is a mode of its own, next to --live/--replay it is a modifier.

Drop ghost contacts near the edge (–live/–record/–gui)

Mask a zone (x_min,y_min,x_max,y_max in mm, repeatable; –filter)

Load occupancy field sets (TOML file or directory)

Completion mode (default: match)

Claim radius x tolerance (default: 2.0)

Missing pins completion may add (default: 1)

Do not bind claimed slots

Incumbent tolerance factor (default 2.0, 1.0 = off)

Contact position smoothing EMA (default 0.6, 0 = off)

Display rotation for the GTK canvas (–gui): quarter turns the evdev positions get before rendering - needed when the desktop shows the panel rotated (e.g. GNOME portrait on a landscape touchscreen)

§background_alpha: Option<u8>

Canvas background opacity for the GTK window (–gui) in percent: 100 = opaque (default), lower values let the desktop show through the black fill - touches and UI stay opaque
