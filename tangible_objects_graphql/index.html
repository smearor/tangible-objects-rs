GraphQL interface for the tangible detection engine.

Exposes the EngineRuntime state through async-graphql: queries read the latest snapshot and static configuration, mutations push [ControlCommand]s back to the device loop and the events subscription streams [DomainEvent]s as TangibleEvents over WebSocket.

serve binds the endpoint on a given address; spawn runs it on a dedicated thread with its own tokio runtime so the synchronous device loop stays untouched.
