Expand description

Control command sent by an interface back to the daemon’s device loop.

Commands are drained by the runtime after each published frame (crate::EngineRuntime::try_recv_command); the concrete behavior is implemented where the owning functionality lands (e.g. filter mode in Phase 4, remote training with the interface crates).

Variants§

§

SetFilterMode

Switch the filter proxy’s suppression policy ([FilterMode::Off] = transparent passthrough). stability overrides the consecutive-matched-frames gate when Some; None keeps the current value.

Fields

§mode: FilterMode

New suppression policy.

§stability: Option<FrameCount>

Consecutive frames a slot must match before suppression starts.

§stage: Option<StageName>

Scope of the stage to reconfigure (EVENT_PIPELINE.md phase 7): Some applies the policy to that stage only, None broadcasts to all tangible stages. Positional stages always ignore SetFilterMode.

§

RegisterStage

Create or claim a pipeline stage for name before any stage = "name" pattern registers - the stage persists until UnregisterStage, independent of pattern lifetimes (EVENT_PIPELINE.md phase 7). Lets a client pre-configure a stage’s SetFilterMode policy.

Fields

§name: StageName

Stage scope name.

§

UnregisterStage

Remove the pipeline stage for name - its suppression state dies with it; patterns of that scope keep matching but are no longer stage-suppressed until a new stage exists.

Fields

§name: StageName

Stage scope name.

§

TrainProfile(PatternName)

Capture a new figure profile with the given name.

§

StartRecording

Start a recording session writing <base_path>.jsonl (frames) and <base_path>.evtest (raw events).

Fields

§base_path: PathBuf

Base path of the recording artifacts, without extension.

§label: Option<RecordLabel>

Ground-truth label applied to recorded frames until changed.

§

StopRecording

Stop the active recording session.

§

SetRecordLabel(Option<RecordLabel>)

Change the ground-truth label applied to subsequent recorded frames.

§

SetCompletion(CompletionConfig)

Replace the missing-pin completion configuration at runtime (TRACKING_STABILIZATION.md). Applies to matching and suppression in all modes from the next frame on.

§

ResetMetrics

Reset the accumulated crate::SessionMetrics counters - e.g. between automated test runs.

§

ShowMessage(String)

Display a user-facing message in the GUI (“Legen Sie Figur 10 auf”) - interfaces steer the operator during test series. None-equivalent empty string clears it.

§

Register

Register a profile or field set at runtime (DYNAMIC_PROFILES.md). Registrations whose fingerprint collides with an already-loaded profile are rejected in the device loop.

Fields

§registration: Box<Registration>

What to register - boxed: ProfileFile makes this variant large; boxing keeps ControlCommand small for the channel.

§owner: Option<Owner>

Optional application name the registration belongs to - UnregisterOwner removes every registration of an owner; D-Bus binds registrations to the caller’s unique name for automatic disconnect cleanup.

§lifetime: Lifetime

Session (default) or Persistent - persistent registrations are written to the daemon’s runtime store on apply.

§reply: Sender<Result<RegistrationApplied, RegistrationError>>

Receives the applied outcome - Ok carries what was registered (the profile’s assigned PatternId), the typed rejection on failure - so interface callers answer with the real result instead of a fire-and-forget “queued”.

§

UpdateProfile

Replace a registered pattern’s geometry/name while keeping its ID (UpdateProfile). Applies to new matches; tracked tangibles keep their recorded pose.

Fields

§id: PatternId

Pattern to replace.

§profile: Box<ProfileFile>

New profile definition - boxed like Register.

§

UnregisterPattern

Remove a dynamically registered pattern by its pattern ID. The ID is never reused.

Fields

§id: PatternId

Pattern to remove.

§

UnregisterFieldSet

Remove a field set by name.

Fields

§name: FieldSetName

Field set to remove.

§

UnregisterDeadZone

Remove a dead zone by name.

Fields

§name: DeadZoneName

Dead zone to remove.

§

UnregisterOwner

Remove every pattern, field set and dead zone owned by owner - used for explicit app cleanup and D-Bus disconnect handling.

Fields

§owner: Owner

Owner name (or the caller’s unique bus name on D-Bus).

§

SetGuiVisible(bool)

Show or hide the daemon-embedded GUI window (crates/gtk, --gui mode). Part of the command vocabulary on all builds - daemons without the gui feature ignore it (the runtime’s gui_visible state is feature-gated).

§

SetDisplayRotation(DisplayRotation)

Quarter-turn the GUI canvas renders (--display-rotation). Same availability as Self::SetGuiVisible - headless daemons ignore it.
