Struct EngineRuntime 

Source 
pub struct EngineRuntime { /* private fields */ }
Expand description

Daemon-side runtime: publishes frames, runs set tracking and receives control commands.

Created once per detection session; the cloneable EngineHandle is handed to interface servers.
