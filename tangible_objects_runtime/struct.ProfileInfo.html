Struct ProfileInfo 

pub struct ProfileInfo {
    pub pattern_id: PatternId,
    pub name: PatternName,
    pub num_points: PinCount,
    pub owner: Option<Owner>,
    pub spawn_on_partial: bool,
    pub spawn_stability: FrameCount,
    pub stage: Option<StageName>,
    pub enabled: bool,
}
Expand description

Static info about a loaded figure profile for query-style responses.

Carried by [crate::EngineHandle]; profiles are static for a session and therefore live on the handle rather than in the per-frame snapshot.

Fields§

§pattern_id: PatternId

Runtime pattern ID assigned when the profile was loaded.

§name: PatternName

Human-readable figure name from the profile file.

§num_points: PinCount

Number of contact pins the figure must have.

§owner: Option<Owner>

Owning application for runtime registrations; None for statically loaded profiles.

§spawn_on_partial: bool

Whether a partial match may spawn this figure (SPAWN_AS_PARTIAL.md).

§spawn_stability: FrameCount

Frames a partial spawn must hold before confirmation.

§stage: Option<StageName>

Pipeline stage this pattern suppresses through (EVENT_PIPELINE.md); None = the general stage.

§enabled: bool

Whether the pattern participates in matching (SetProfileEnabled command) - disabled profiles stay registered but produce no matches.
