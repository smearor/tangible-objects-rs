Shared runtime: event distribution, state snapshots and the control channel between the daemon’s device loop and the interface crates.

EngineRuntime lives in the daemon’s synchronous device loop: every processed [tangible_objects_engine::EngineFrame] is published once, updating the snapshot and broadcasting domain events. Interface crates (GraphQL, D-Bus, MCP) receive a cloneable EngineHandle with stream, snapshot and control access - they never touch the engine directly.
