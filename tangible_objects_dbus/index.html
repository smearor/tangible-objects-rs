D-Bus interface for the tangible detection engine.

Exposes the EngineRuntime state on the session bus: org.tangibleobjects.Engine serves org.tangibleobjects.Engine1 at /org/tangibleobjects/Engine with methods for queries/control and signals for domain events.

serve runs the service; spawn runs it on a dedicated thread with its own tokio runtime so the synchronous device loop stays untouched.
