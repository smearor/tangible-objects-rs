Crate tangible_objects_engine 

Source
Expand description

Headless detection engine for tangible objects on multitouch surfaces.

Feeds raw multitouch events (evdev or evtest recordings) through the slot state machine, matches geometric figure patterns and tracks detected tangibles across frames. Linux-only for device access; the detection core itself is platform-agnostic.
