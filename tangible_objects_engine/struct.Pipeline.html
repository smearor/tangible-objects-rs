Struct Pipeline

pub struct Pipeline { /* private fields */ }
Expand description

Ordered stage chain plus the shared emit boundary (EVENT_PIPELINE.md phase 2).

Events accumulate until SYN_REPORT; per stage, [TangibleStage]’s classification decides which slots are suppressed, then the boundary shapes the emitted frame once - drops, retraction injections, guarded withholding, legacy events - ending in SYN_REPORT.

Today the chain holds exactly one general TangibleStage over all patterns - the backward-compatible --filter parity case. Later phases add stage scopes, edge/zone/field stages and per-stage registration.

Creates a pipeline with one general tangible stage (default Guarded policy) - today’s single-stage parity. Additional stages are appended with [Self::push_stage].

Appends an edge stage: contacts within margin of the surface bounds are suppressed - ghost contacts some panels emit at the axis bounds.

Appends a zone stage: any contact inside one of zones is suppressed - play-area masking.

pub fn set_field_sets(&mut self, sets: Vec<FieldSet>)

Syncs the field stage’s sets - creates it lazily on first use. suppress-enabled field sets then suppress their contacts via the stage (replaces the daemon-side merge into the general stage’s matched set).

Source

pub fn ensure_tangible_stage(&mut self, scope: StageName) -> bool

Ensures a tangible stage exists for scope - created lazily the first time a stage = "name" profile registers (EVENT_PIPELINE.md phase 4). New stages start with empty hysteresis - the conservative default: nothing suppressed until their own gate passes. Returns true when a stage was created.

Source

pub fn tangible_scopes(&self) -> impl Iterator<Item = &StageName>

Scopes of all tangible stages - diffed against the engine’s pattern scopes to detect stale stages.

Source

pub fn remove_tangible_stage(&mut self, scope: &StageName) -> bool

Removes the tangible stage for scope - the scope’s last pattern is gone; its hysteresis dies with it. Returns true when a stage was removed.

Source

pub fn register_stage(&mut self, scope: StageName) -> bool

Claims or creates a tangible stage for scope (RegisterStage control command): explicit stages survive sync_scopes until UnregisterStage - a client can pre-configure a stage’s policy before any pattern with that scope exists. Returns true when a stage was newly created - the caller emits StageRegistered; claiming an existing stage is silent.

Source

pub fn unregister_stage(&mut self, scope: &StageName) -> bool

Removes the tangible stage for scope (UnregisterStage) - explicit or not, its suppression state dies with it; patterns of that scope keep matching but are no longer stage-suppressed until a new stage exists. Returns true when a stage was removed.

Source

pub fn sync_scopes(&mut self, scopes: &HashSet<StageName>) -> ScopeChanges

Syncs the tangible stages with the pattern scopes currently registered on the engine: scopes not yet covered get a stage, scopes whose last pattern is gone lose it. Returns the applied changes - the caller reports them as lifecycle events.

Source

pub fn stage_metrics(&self) -> impl Iterator<Item = &StageMetrics>

Per-stage metric snapshots, in declaration order - which stage is suppressing what (phase 6).

Source

pub fn set_legacy_mode(&mut self, legacy: LegacyMode)

Switches the legacy single-touch event policy (BTN_TOUCH, ABS_X, ABS_Y). LegacyMode::Auto (default) emits them only while a contact is live on the virtual device.

Source

pub fn set_mode( &mut self, mode: FilterMode, stability: Option<FrameCount>, scope: Option<&StageName>, )

Switches the suppression policy (SetFilterMode control command): scope Some applies it to the matching stage only, None broadcasts to all tangible stages - positional stages ignore SetFilterMode regardless. stability replaces the gate when Some.

Source

pub fn push(&mut self, event: RawEvent)

Buffers one source event for the current frame.

Source

pub fn finish( &mut self, matched: &SlotSet, touches: TouchSet<'_>, ) -> Vec<InputEvent>

Finishes the buffered frame with matched treated as the general stage’s set - the unscoped convenience for single-scope setups.

Source

pub fn finish_scoped( &mut self, matched: &HashMap<Option<StageName>, SlotSet>, touches: TouchSet<'_>, ) -> Vec<InputEvent>

Finishes the buffered frame: every stage classifies the subset of matched keyed by its own scope (input masking), then the emit boundary merges the stage decisions - the mechanism sees the union - into the emitted frame, ending in SYN_REPORT.

Source

pub fn suppressed_slots(&self) -> impl Iterator<Item = TouchPointSlot> + '_

Union of every stage’s suppressed slots after the last finish/finish_scoped - includes the stateless stages (edge/zone/field) alongside the tangible stage, so callers can report the real forwarded/suppressed split.
