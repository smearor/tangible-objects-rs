Struct SeatTracker

pub struct SeatTracker { /* private fields */ }
Expand description

Session registry and per-frame seat tracker (TANGIBLE_OBJECTS_TABLE_TOP_SEAT.md).

Holds the claimed SeatSessions with their rosters and, fed with each frame’s TrackedSet, binds marker tangibles to seats, re-derives [SeatPose]s and reports the roster/anchor changes as SeatEvents - the seat-domain counterpart of crate::SetTracker.

Ownership follows the profile-claim contract: a session has exactly one owner, only the owner may mutate its roster, and Self::remove_by_owner implements the UnregisterOwner/disconnect cleanup. The absent hysteresis is sticky by design - an Absent seat keeps its last pose until the marker returns or the application removes the seat.

Adds a seat to a claimed session - marker-backed (marker: Some, starts Absent until the first bind) or virtual (marker: None, keeps pose). Only the session owner may add seats; names are unique within the session.

Source

pub fn update_seat( &mut self, id: SeatId, owner: &Owner, name: Option<SeatName>, marker: Option<Option<PatternId>>, pose: Option<SeatPose>, ) -> Result<(TableTopSeat, bool), RegistrationError>

Mutates a seat addressed by its globally unique ID - None fields keep their value; marker’s inner None clears the marker so the seat turns virtual. Only the session owner may mutate. Returns the updated seat and whether its pose changed.

Source

pub fn remove_seat( &mut self, id: SeatId, owner: &Owner, ) -> Result<TableTopSeat, RegistrationError>

Removes a seat addressed by its globally unique ID - only the session owner may remove. Returns the removed seat.

Source

pub fn remove_by_owner(&mut self, owner: &Owner) -> Vec<SeatSession>

Drops every session owned by owner - the UnregisterOwner and D-Bus-disconnect cleanup. Returns the removed sessions so the caller can report their release.

Source

pub fn update(&mut self, tracked: TrackedSet<'_>) -> Vec<SeatEvent>

Feeds the current frame’s tracked tangibles and returns the seat events since the previous update - binds marker instances, re-derives anchored poses and flips the anchor state.

Per session a tangible anchors at most one seat: the incumbent binding wins, otherwise seats pick the smallest free matching [TangibleId] in roster order (deterministic spawn order).
