Typed GraphQL client for the tangible-objects daemon (GRAPHQL_CLIENT.md).

GraphQLClient covers the full schema surface: all queries, mutations and subscriptions, typed end to end - model types in, model types out. Documents are built by cynic fragments checked against crates/graphql/schema.graphql at compile time (no hand-written query strings); subscriptions run over the graphql-transport-ws protocol on a raw tokio-tungstenite socket.

§Quickstart

use tangible_objects_client::Endpoint;
use tangible_objects_client::GraphQLClient;
use tangible_objects_client::ClientError;

let endpoint = Endpoint::resolve(None); // flag/env > client.toml > default
let client = GraphQLClient::new(endpoint)?;
for tangible in client.tangibles().await? {
    println!("{} @ ({:.1},{:.1})", tangible.pattern_name.as_str(), tangible.center.x, tangible.center.y);
}
