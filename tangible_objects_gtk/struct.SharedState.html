Expand description

Snapshot the draw functions consume - written by the device thread once per SYN_REPORT frame, read by the ~30 fps GTK timer.

Fields§

§touches: Vec<TouchPoint>

Active touch points.

§matches: Vec<PatternMatch>

Raw pattern matches of the last frame (live view).

§tracked: Vec<TrackedTangible>

Currently tracked tangibles (pending flags render dimmed).

§calibration: Option<Calibration>

Effective axis calibration (mm conversion for the canvas scale).

§calibration_source: Option<CalibrationSource>

Where the active calibration came from (device vs profile override) - None while uncalibrated.

§metrics: SessionMetrics

Accumulated session counters (Metrics card).

§stable_frames: u32

Consecutive frames the contact set held the same size.

§stable: bool

Contact set stable long enough for profile capture.

§mode: GuiMode

Live vs. training visualization.

§device_error: Option<String>

Device-open failure shown instead of the surface.

§device_info: Option<DeviceInfo>

Reported input-device identity + raw axis ranges (device card).

§message: Option<String>

User-facing message pushed via an interface (ShowMessage).

§visible: bool

Whether the window should be shown (SetGuiVisible).

§rotation: DisplayRotation

Display rotation the mm→px mapping applies (--display-rotation)

  • the evdev stream always speaks the panel’s native frame.
§background_alpha: BackgroundAlpha

Canvas background opacity (--background-alpha, the alpha toggle and SetBackgroundAlpha commands).

§background_alpha_request: Option<BackgroundAlpha>

Alpha change requested by the control-bar toggle - the device thread drains it into the runtime (SetBackgroundAlpha semantics) so the interface-visible state stays authoritative.

§dead_zones: Vec<DeadZone>

Registered dead zones - the overlay data set.

§dead_zones_visible: bool

Whether the dead-zone overlay is drawn (SetDeadZonesVisible/--dead-zones-visible).

§spells_visible: bool

Spell-gesture overlay visible (SetSpellsVisible, SPELLS.md).

§trajectories: Vec<Vec<Vec2<Millimeters>>>

Live gesture trajectories per slot - debug polylines for the spell overlay.

§last_spell: Option<(SpellMatched, Instant)>

Most recent spell match and when it fired - the match flash.

§dead_zone_filtered: ContactCount

Contacts dropped by dead-zone filtering on the last frame.

§field_set_count: FieldSetCount

Registered field sets (snapshot field_sets count).

§field_count: FieldCount

Occupancy fields across all field sets.

§occupied_fields: FieldCount

Fields currently occupied.

§edge_margin: Millimeters

Edge margin in millimeters - the ingest-filtered strip at the surface edges.

§edge_margin_visible: bool

Whether the edge-margin overlay is drawn (SetEdgeMarginVisible/--edge-margin-visible).

§fields_visible: bool

Whether the field-set overlay is drawn (SetFieldsVisible/--fields-visible).

§field_sets: Vec<FieldSet>

Registered field sets - the overlay data set.

§field_set_rows: Vec<FieldSetRow>

Display rows of the registered field sets (name, owner, enabled, field count) - the field-sets card’s data.

§profiles: Vec<ProfileInfo>

Loaded and dynamically registered figure profiles - the profiles card’s data (positions come from tracked).

§ruler_visible: bool

Whether the ruler overlay is drawn (SetRulerVisible/--ruler-visible).

§grid_visible: bool

Whether the grid overlay is drawn (SetGridVisible/--grid-visible).

§positions_visible: bool

Whether the positions overlay is drawn (SetPositionsVisible/--positions-visible).

§touch_passthrough: bool

Whether touches pass through to the desktop except on GUI elements (SetTouchPassthrough/--touch-passthrough).

§filter_mode: FilterMode

Selected suppression policy (SetFilterMode command + --filter-mode start value) - display state.

§completion: CompletionConfig

Active missing-pin completion config (Parameters card).

§legacy_mode: LegacyMode

Legacy single-touch event policy (Parameters card).

§filter_stability: u64

Filter pipeline stability frames, 0 until a SetFilterMode command carries stability (Parameters card).

§profile_bounds_visible: bool

Draws the bounding box of every matched figure - debugging aid (GUI-local toggle, Parameters card).

§render_mode: TangibleRenderMode

Which layers the live view draws per matched tangible (GUI-local toggle on the visualization card).

§pattern_styles: Vec<PatternStyle>

Declared profile styles (color/shape) keyed like engine.patterns() - the draw loop colors figures and outlines physical shapes from it.

§incoming_contacts: ContactCount

Active contacts before ingest filtering on the last frame.

§edge_filtered: ContactCount

Touches dropped by edge-margin filtering on the last frame.

§mode_suppressed: ContactCount

Touches the filter proxy would suppress under the current filter_mode (tangible-bound slots, suppress fields, or all contacts in TangiblesOnly) - virtual count, the GUI has no proxy.

§forwarded: ContactCount

Touches the filter proxy would forward - touches minus mode_suppressed. Virtual count in --gui mode.

§command_handle: Option<EngineHandle>

Command channel handle - the control-bar buttons issue the same ControlCommands the interfaces do.
